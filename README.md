# fb2read

Читалка книг FB2 и EPUB для терминала. Один файл, только стандартная
библиотека Python 3.8+.

## Установка

```bash
pip install .
# либо просто
chmod +x fb2read.py && cp fb2read.py ~/.local/bin/fb2read
```

## Запуск

```bash
fb2read book.fb2            # читать книгу
fb2read book.epub           # EPUB работает так же
fb2read book.fb2.zip -2     # книжный разворот из двух страниц
fb2read ~/books             # библиотека: список книг в каталоге
fb2read                     # список недавних книг с прогрессом

fb2read book.fb2 --dump | less -R   # текст в конвейер
fb2read book.fb2 --toc              # оглавление
fb2read book.fb2 --info             # сведения о книге и внесённые правки
```

Полезные ключи: `-w 72` — ширина колонки, `-s 2` — межстрочный интервал,
`--theme night` — цветовая тема, `-2` / `-1` — разворот или одна колонка,
`--images off` — без картинок, `--no-mouse` — не захватывать мышь,
`--from-start` — не восстанавливать позицию.

## Клавиши

| Клавиши | Действие |
|---|---|
| `j` `k` `↓` `↑` | строка вниз / вверх |
| `Space` `PgDn` `→` `f` / `b` `PgUp` `←` | страница вперёд / назад |
| `d` `u` | полстраницы |
| `g` `G` | начало / конец книги |
| `[` `]` | предыдущая / следующая глава |
| `t` `o` | оглавление |
| `/` `n` `N` | поиск и переходы по совпадениям |
| `l` | список всех совпадений с контекстом |
| `M` | поставить или снять закладку |
| `'` `"` | закладки: переход, удаление, экспорт |
| `Enter` `Backspace` | перейти к сноске / вернуться |
| `1` `2` `v` | одна колонка / книжный разворот |
| `s` | межстрочный интервал (1 / 2 / 3) |
| `+` `=` `-` | ширина колонки |
| `c` | тема: авто → ночь → сепия → день |
| `p` | показать иллюстрацию с экрана |
| `i` | сведения о книге |
| `Ctrl+L` | перерисовать экран |
| `m` | отпустить мышь и вернуть захват |
| колесо, клик | листать; клик по сноске или картинке; правая кнопка — назад |
| `?` `h` | справка |
| `q` | выход, позиция сохраняется |

Размер шрифта задаётся терминалом (`Ctrl` + `+` в большинстве эмуляторов,
`setfont` в консоли Linux); текст сам переливается под новый размер окна.

## Что умеет разбор

* `.fb2`, `.fb2.zip`, `.fbz`, `.epub`; кодировка определяется даже без объявления;
* EPUB 2 и 3: порядок чтения берётся из spine, оглавление из `nav` или NCX,
  ссылки на сноски работают между файлами книги, заголовки, списки, цитаты
  и таблицы раскладываются так же, как в FB2;
* заголовки, вложенные разделы, эпиграфы, цитаты, стихи, таблицы, сноски;
* курсив и полужирный доходят до экрана, ширина символов считается честно
  (иероглифы — два знакоместа, эмодзи — два, диакритика — ноль);
* починка типичных поломок: неэкранированный `&`, `&nbsp;` и прочие HTML-сущности,
  мусор до и после документа, управляющие байты. Все правки видны в `--info`;
* `<binary>` вырезаются до разбора, поэтому книги с картинками открываются
  вдвое быстрее и не занимают лишнюю память: запоминаются только границы
  вложения в файле, а данные читаются в момент показа.

## Иллюстрации

Клавиша `p` показывает картинку, попавшую на экран (если их несколько —
предлагает выбрать). Читалка выходит из curses, рисует изображение на весь
экран и по любой клавише возвращается к тексту.

| Терминал | Как рисуется |
|---|---|
| kitty | графический протокол kitty (PNG отправляется как есть) |
| iTerm2, WezTerm | OSC 1337, любой формат |
| любой с `chafa` | внешний конвертер, цветные символы |
| любой с `img2sixel` | sixel |
| остальные | сообщение с подсказкой поставить `chafa` |

Способ выбирается сам, но его можно задать: `--images kitty`, `--images chafa`,
`--images off`. В настройках он не сохраняется — зависит от того, где книгу
открыли.

Позиция чтения, тема, интервал и режим колонок хранятся в
`$XDG_DATA_HOME/fb2read/positions.json` (по умолчанию `~/.local/share`).

## Библиотека

Без аргумента читалка показывает недавние книги с процентом чтения, с
каталогом — все книги в нём; автора и название достаёт без полного разбора,
поэтому список строится быстро. Дочитанные книги приглушены. Список
листается `j` `k`, `PgUp` `PgDn`, колесом мыши, `g` `G`; `Enter` или клик
открывают книгу, `q` выходит. После чтения возвращаешься к списку с
обновлённым прогрессом. Если вывод перенаправлен в файл или конвейер,
список печатается текстом и читалка не занимает экран.

## Поиск

`/` ищет по всей книге сразу: показывает, какое совпадение по счёту из
скольких, подсвечивает все попадания на экране и переходит по ним клавишами
`n` и `N` с переходом через конец. `l` открывает список найденного — каждая
строка с процентом по книге и кусочком текста вокруг совпадения, выбор
переносит туда. Регистр не важен, ё и е считаются одной буквой. Пустой
запрос сбрасывает поиск и подсветку.

## Закладки

`M` ставит закладку на текущее место и снимает её повторным нажатием;
отмеченные абзацы помечаются полоской на левом поле. `'` открывает список
закладок с процентом по книге и первой строкой текста: `Enter` переносит
туда, `d` удаляет, `e` выгружает всё в markdown — заголовок книги, автор и
по несколько абзацев цитаты под каждой закладкой. Закладки хранятся рядом с
позицией чтения и переживают перезапуск.

## Мышь

Колесо листает текст, оглавление и список книг; клик по подчёркнутому
маркеру сноски открывает её, клик по метке иллюстрации показывает картинку,
правая кнопка возвращает из сноски. Пока мышь захвачена, терминал отдаёт
клики программе и обычное выделение текста не работает — в большинстве
терминалов помогает Shift, а иначе захват снимается клавишей `m` или ключом
`--no-mouse`. Используются SGR-репорты, поэтому клики приходят и в окнах
шире 223 колонок.

## Настройки

`fb2read --write-config` кладёт образец в `~/.config/fb2read/config.ini`
со всеми действиями и их клавишами по умолчанию:

```ini
[reader]
# width = 80          ширина текстовой колонки
# spacing = 1         межстрочный интервал: 1, 2 или 3
# columns = 1         1 — одна колонка, 2 — книжный разворот
# theme = auto        auto, night, sepia, day
# images = auto       auto, kitty, iterm, chafa, sixel, off
# mouse = yes         захватывать ли мышь

[keys]
# next_chapter = ]
# prev_chapter = [
# quit = q, Q
```

Понимаются одиночные символы, имена `space`, `enter`, `backspace`, `tab`,
`esc`, `delete`, стрелки, `pgup`, `pgdn`, `home`, `end` и сочетания вида
`ctrl-l`. Справка по `?` строится из действующей раскладки, так что всегда
показывает ваши клавиши, а не зашитые. Проблемы чтения файла и неверные
значения в `[reader]` сообщаются при старте, непонятные клавиши и
неизвестные действия в `[keys]` просто не учитываются — читалка в любом
случае продолжает работать.

Порядок старшинства: ключ командной строки, затем конфиг, затем то, что
читалка запомнила с прошлого запуска. Путь к другому файлу — `--config`.

## Разработка

```bash
pip install -e ".[test]"
pytest
```

Тесты делятся на две части. `tests/test_core.py` проверяет разбор, починку
битых файлов, перенос строк и хранение состояния обычными вызовами функций.
`tests/test_ui.py` запускает читалку целиком в псевдотерминале и читает
экран эмулятором `pyte` — так проверяются вещи, которые иначе видны только
глазами: разворот на две страницы, переход по сноске, начертание символов,
поведение при `LC_ALL=C` и при изменении размера окна.

Приёмы, важные для устойчивости этих тестов:

* размер окна выставляется до запуска программы, иначе первый кадр
  рисуется в другом размере и модель экрана расходится с реальностью;
* дочернему процессу отдаётся управляющий терминал, иначе ядро не шлёт
  `SIGWINCH` и ресайз не проверить;
* после нажатий посылается `Ctrl+L`: curses обновляет только изменившиеся
  ячейки, а полная перерисовка синхронизирует эмулятор с программой.

## Чего пока нет

* выключка по формату: строки переносятся по словам, но правый край
  колонки остаётся неровным;
* расстановка переносов в узких колонках;
* ленивая вёрстка: книга раскладывается в строки целиком при открытии,
  поэтому очень большие файлы могут открываться не мгновенно.
